# Product Context

Product working name: **Bambinos**

This file is the source of truth for product intent. It describes who the product is for and what must be true of the content. It does not specify visual design, interaction design, frontend implementation, or backend implementation.

## Primary user

Parents

## Primary task

Explore parenting articles

## Prototype question

Landing page of parenting articles

What this prototype is meant to answer: whether a landing surface of parenting articles supports parents in exploring that content.

## Required content and states

Parenting related content

In scope for this context:

- Parenting articles as the core content type
- Content a parent would reasonably expect when exploring parenting topics
- Content states needed for exploration (for example: content available to browse, and the absence of articles if none are present)

Out of scope here: how those states look, how they are built, or how they are stored.

## Explicit exclusions

- Any design decisions
- Frontend
- Backend

Do not use this document to choose layout, visual style, components, navigation patterns, tech stack, APIs, data models, or infrastructure.

Not provided.
